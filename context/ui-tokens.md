# UI Tokens

## Colors

- Page background: #F7F2E8
- Surface: #FFFDF9
- Primary text: #2B2118
- Muted text: #71675E
- Primary action: #C94F67
- Primary action hover: #B94359
- Supporting green: #A8B69A
- Border: #DED7CD
- Error: #B42318

## Typography

- Display headings: Fraunces
- UI and body: Inter

Fonts must be loaded using next/font.

## Layout

- Maximum page width: 1280px
- Desktop: two columns
- Mobile: one stacked column
- Card radius: 16px
- Control radius: 10px
- Chip radius: full (pill) — see the Chip pattern in `context/ui-registry.md`
- Card padding: 24px
- Touch target: at least 44px
- Borders: 1px
- Shadows: subtle only

## Principles

- Warm editorial pastry aesthetic
- Clear hierarchy
- Generous whitespace
- Accessible contrast
- No gradients
- No glassmorphism
- No generic chatbot bubbles
- No unnecessary animations
