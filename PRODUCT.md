# BakeFix

BakeFix diagnoses common pastry problems.

## User flow

1. User selects a pastry category.
2. User describes what went wrong.
3. User may paste the recipe.
4. User selects dietary constraints.
5. The app returns likely causes, a rescue plan and advice for next time.

## MVP constraints

- One page
- No authentication
- No database
- No image uploads
- No saved history
- One AI request per diagnosis
- Responsive and accessible
